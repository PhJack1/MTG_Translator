Расширение для браузера Firefox для автоматического перевода названий карт Magic: The Gathering на самых популярных сайтах с декл-листами.

## 🎯 Возможности

- **Перевод в реальном времени**: Мгновенно переводит названия карт MTG на выбранный язык
- **Многоязычная поддержка**: 10 доступных языков (FR, ES, DE, IT, PT, JA, KO, RU, ZH, ZH-TW)
- **Поддерживаемые сайты**: MTGTop8, MTGGoldfish, Moxfield, MTGDecks.net, DeckStats, Archidekt, TappedOut, EDHREC и другие (полный список см. в `assets/selectors.json`)
- **Умный локальный кэш**: Использует IndexedDB для хранения переводов и сокращения вызовов API
- **Режим наведения**: Отображайте оригинальное английское название при наведении на переведенную карту
- **Импорт/Экспорт**: Сохраняйте и делитесь своей пользовательской базой переводов

### Ручная установка (для разработчиков)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/PhJack1/MTG_Translator.git
cd MTG_Translator
```

2. В Firefox:
   - Введите `about:debugging` в адресную строку
   - Нажмите «Этот Firefox» в левом меню
   - Нажмите «Загрузить временное дополнение»
   - Выберите файл `manifest.json` в папке проекта

## 🚀 Использование

1. **Выберите язык**: Нажмите на иконку расширения и выберите целевой язык из доступных флагов

2. **Переведите страницу**: 
   - Посетите поддерживаемый сайт (например, mtgtop8.com)
   - Нажмите кнопку «Перевести карты на странице»
   - Названия карт мгновенно переводятся!

3. **Просмотр оригинального названия**: Наведите курсор на переведенную карту, чтобы временно отобразить её английское название

4. **Добавить перевод вручную**:
   - Введите английское название в первое поле
   - Введите перевод во второе поле
   - Нажмите «Сохранить»

5. **Экспорт/Импорт базы данных**:
   - **Экспорт**: Загрузите базу переводов в формате JSON
   - **Импорт**: Перетащите JSON-файл для слияния переводов

### 🤖 Автоматический Перевод
Расширение теперь может автоматически переводить карты MTG без ручного вмешательства. Просто установите флажок "Автоматический перевод" в всплывающем окне и выберите целевой язык. Перевод будет выполняться автоматически при загрузке каждой поддерживаемой страницы и также обнаружит динамические изменения DOM (сайты вроде Moxfield с живым редактированием).

## 🔧 Техническая архитектура

### Стек
- **Manifest V2** (Firefox)
- **JavaScript модули (ES6)**
- **IndexedDB** для локального кэширования
- **API Scryfall** для переводов

### Структура проекта
```
MTG_Translator/
├── manifest.json           # Конфигурация расширения
├── popup/
│   ├── popup.html         # Пользовательский интерфейс
│   ├── popup.js           # Логика всплывающего окна
│   └── popup.css          # Стили
├── content/
│   └── content.js         # Скрипт, внедряемый в веб-страницы
├── background/
│   ├── background.js      # Service worker
│   ├── translations.js    # API переводов
│   ├── scryfall.js        # Вызовы API Scryfall
│   ├── db.js              # Управление IndexedDB
│   ├── import.html        # Интерфейс импорта
│   ├── import.js          # Логика импорта
│   └── import.css         # Стили импорта
└── assets/
    └── selectors.json     # CSS-селекторы для каждого сайта
```

### Как это работает

1. **Обнаружение**: Контентный скрипт идентифицирует элементы с названиями карт через CSS-селекторы, специфичные для сайта
2. **Локальный кэш**: Проверяет наличие перевода в IndexedDB
3. **API Scryfall**: Если отсутствует, запрашивает Scryfall (ограничено ~10 запросов/сек)
4. **Кэширование**: Сохраняет новый перевод локально
5. **Отображение**: Заменяет текст в DOM с управлением наведением

## 🛠️ Добавление нового сайта

Расширение поддерживает любой веб-сайт путём добавления CSS-селекторов в `assets/selectors.json`. Этот файл сопоставляет веб-домены с HTML-элементами, содержащими названия карт.

### Конфигурация селекторов

Каждая запись сайта требует:
- **selector**: CSS-селектор, указывающий на элемент, содержащий название карты
- **childIndex** (опционально): Если название находится в дочернем элементе, укажите какой (0 = первый)
- **mode** (опционально): Используйте `"composite"` для сложных структур с селекторами родителя и ребёнка

### Базовый пример

```json
{
  "новый-сайт.com": [
    {
      "selector": "css-селектор-для-карт",
      "childIndex": 0
    }
  ]
}
```

### Пример composite (как Moxfield)

Для сайтов с вложенными структурами:

```json
{
  "moxfield.com": [
    {
      "selector": "a.table-deck-row-link.text-body",
      "mode": "composite",
      "childSelector": "span.underline"
    }
  ]
}
```

### Шаги по добавлению сайта

1. Откройте инструменты разработчика браузера (F12)
2. Инспектируйте элемент с названием карты, чтобы найти его CSS-селектор
3. Добавьте запись в `assets/selectors.json` с селектором
4. Протестируйте, перезагрузив расширение и посетив сайт
5. При необходимости уточните селектор

Смотрите `assets/selectors.json` для текущих поддерживаемых сайтов и их конфигураций.
